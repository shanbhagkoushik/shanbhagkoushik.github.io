The idea behind this site is that everything here — this paragraph included — lives as a plain markdown file in the repo, under `content/blog`. No database, no build step. When you publish a new post from the `/admin` page, it commits a new file straight to GitHub, and the site picks it up automatically.

## Why this setup

A few reasons this is worth keeping simple:

- It's free to run indefinitely on GitHub Pages.
- Every post is just a file you can also read and edit by hand.
- There's nothing to keep patched or paying for.
